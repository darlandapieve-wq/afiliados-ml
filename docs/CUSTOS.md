# Estimativa de custos mensais

Valores conferidos em outubro/2026. Os planos gratuitos podem mudar, então confira os preços nos sites oficiais.

| Item | Uso típico (1 usuário, ~10 posts/dia) | Custo |
|---|---|---|
| Supabase Free (Postgres 500 MB, Storage 1 GB, 5 GB de tráfego, 500 mil chamadas de Edge Function) | Banco < 50 MB; artes ~150 KB e vídeos ~0,5 MB cada; worker = ~43 mil chamadas/mês | **R$ 0** |
| Render Static Site (ou Netlify/Cloudflare Pages) | site estático | **R$ 0** |
| GitHub (repositório + Actions de CI e keep-alive) | poucos minutos/mês | **R$ 0** |
| APIs Meta, TikTok, YouTube, Pinterest, Telegram, Mercado Livre | dentro das cotas padrão | **R$ 0** |
| IA (opcional) | Gemini: cota gratuita · Claude: pago por uso (centavos por legenda) | R$ 0 a ~R$ 10 |
| Domínio próprio (opcional) | `.com.br` | ~R$ 40/ano |
| **Total** | | **R$ 0/mês** (sem IA paga e sem domínio) |

## Quando considerar pagar
- **Supabase Pro (US$ 25/mês):** elimina a pausa por inatividade, inclui backups diários de 7 dias, 8 GB de banco e 100 GB de arquivos. Faz sentido se os agendamentos não podem falhar ou se as artes e vídeos passarem de ~1 GB.
- **Limpeza de arquivos:** para ficar no plano gratuito, exclua artes e vídeos de campanhas antigas (aba *Artes e vídeo*).
