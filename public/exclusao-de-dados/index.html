Instruções de exclusão de dados

Para excluir seus dados do ML Afiliados:

  1. Entre no aplicativo e abra Configurações › Excluir conta e todos os dados. A exclusão é imediata e remove produtos, campanhas, imagens, tokens e registros.
  2. Para remover apenas a conexão com Facebook/Instagram: Integrações › Desconectar (os tokens são apagados). Você também pode remover o app em Facebook › Configurações › Segurança e login › Integrações comerciais.
  3. Se não conseguir acessar, envie um e-mail para darlan.dapieve@ifpr.edu.br com o assunto "Exclusão de dados — ML Afiliados". Atendemos em até 15 dias.
